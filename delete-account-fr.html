Supprimer le compte - Carnet de Chasse

Comment supprimer votre compte

Pour supprimer votre compte et toutes vos données, suivez ces étapes dans l'application :

  1. Ouvrez l'application Carnet de Chasse
  2. Appuyez sur votre photo de profil (en haut à droite)
  3. Faites défiler jusqu'en bas de l'écran de profil
  4. Appuyez sur le bouton « Supprimer mon compte » (en rouge)
  5. Confirmez la suppression

Quelles données sont supprimées

Lorsque vous supprimez votre compte, les éléments suivants sont effacés définitivement :

  • Votre profil (nom, photo, téléphone, région)
  • Toutes vos chasses
  • Votre équipement (armes à feu, chiens)
  • Vos documents et dépenses
  • Vos territoires de chasse
  • Vos messages du chat
  • Vos abonnements aux notifications push
  • Votre compte de connexion

Cette action est irréversible. Une fois le compte supprimé, les données ne peuvent pas être récupérées.

Contact

Si vous ne pouvez pas accéder à l'application pour supprimer votre compte, contactez-nous à l'adresse agendadecaza@gmail.com en indiquant l'e-mail avec lequel vous vous êtes inscrit, et nous procéderons à la suppression manuelle.
